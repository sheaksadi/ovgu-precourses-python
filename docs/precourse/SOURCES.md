# Sources, inspiration, and inspection limits

Prepared 2026-09-18. The German tasks in this package are newly written; CS50 problem statements and solutions have not been copied or translated.

## Primary teaching references

- [CS50P week 0](https://cs50.harvard.edu/python/weeks/0/): variables, functions, values, input/output and pseudocode.
- [CS50P week 1](https://cs50.harvard.edu/python/weeks/1/): decisions and comparisons.
- [CS50P week 2](https://cs50.harvard.edu/python/weeks/2/): repetition and lists. We deliberately choose a smaller subset.
- [Indoor Voice](https://cs50.harvard.edu/python/psets/0/indoor/) and [Playback Speed](https://cs50.harvard.edu/python/psets/0/playback/): inspiration for small, observable input/output contracts; alternatives, not extra required lessons.
- [Coke Machine](https://cs50.harvard.edu/python/psets/2/coke/): reserve inspiration for state and termination if a class is ready for `while`.
- [Little Professor](https://cs50.harvard.edu/python/psets/4/professor/): reserve quiz inspiration, not the mandatory project.
- [CS50 license](https://cs50.harvard.edu/python/license/): check attribution and licensing if directly adapting course material later. Do not silently relicense copied tasks as project code.

The temperature project is an original choice for this short course: fixed data, visible boundaries, no accounts/network and a natural bridge to mathematics.
